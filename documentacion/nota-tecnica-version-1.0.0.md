# Nota técnica de versión 1.0.0

**Proyecto:** Educación Virtual RD  
**Tipo de versión:** documentación y modelado inicial  
**Autor:** Jeury Javier Sánchez

## Contenido de la versión

Esta versión reúne la documentación principal del sistema, los requisitos funcionales RF01–RF05, las historias de usuario y los criterios de aceptación. También incluye fuentes de cuatro modelos UML, una explicación de la arquitectura cliente-servidor y un registro de los cambios documentales.

## Cambios controlados

- Se organizó el alcance funcional del sistema.
- Se describieron los principales usuarios y sus necesidades.
- Se añadieron modelos de referencia para representar funciones, estructura y flujos.
- Se documentaron las responsabilidades de frontend, backend, API y base de datos.
- Se revisaron las descripciones de los Issues y se cerraron las tareas atendidas dentro de la fase documental.

## Limitaciones conocidas

La plataforma no se declara funcional. No se incluye una implementación conectada de frontend, backend o base de datos. Tampoco se afirma que existan pruebas de software ejecutadas ni un despliegue en producción. Los archivos UML incluidos son fuentes editables; las capturas de una herramienta externa deben generarse desde esa herramienta si son necesarias para la entrega académica.

## Próximo paso técnico

El siguiente paso es seleccionar la tecnología de implementación, diseñar el esquema inicial de datos y crear las tareas de desarrollo separadas por módulo. Después deberán desarrollarse y probarse el registro, el inicio de sesión, la consulta de cursos, las evaluaciones y los reportes.

## Estado

La versión 1.0.0 se considera cerrada para la organización documental inicial. La implementación funcional se mantiene fuera de su alcance.
