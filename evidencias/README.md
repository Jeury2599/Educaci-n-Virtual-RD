# Evidencias técnicas

Esta carpeta sirve para reunir capturas y enlaces que demuestren el trabajo realizado durante la asignatura.

## Enlaces principales

- Repositorio: https://github.com/Jeury2599/Educaci-n-Virtual-RD
- Issues: https://github.com/Jeury2599/Educaci-n-Virtual-RD/issues
- README principal: https://github.com/Jeury2599/Educaci-n-Virtual-RD/blob/main/README.md
- Modelos UML fuente: ../diagramas-uml/

## Capturas que conviene conservar

1. Página principal del repositorio con el README visible.
2. Sección del README donde se explican frontend, backend y base de datos.
3. Listado de Issues cerrados.
4. Detalle de los Issues seleccionados para seguimiento técnico.
5. Tablero de GitHub Projects con el estado de las tareas.
6. Diagramas exportados desde la herramienta utilizada para modelarlos.
7. Pantallas o prototipos de la interfaz del sistema.

## Cómo guardar una captura

Abre la pantalla que quieres documentar y, en Windows, pulsa Win + Shift + S. Selecciona el área necesaria y guarda la imagen. Utiliza nombres claros, por ejemplo README-principal.png, Issues-cerrados.png o tablero-projects.png.

## Estado de las evidencias

El repositorio incluye los enlaces y los archivos fuente de los modelos. Las capturas deben ser imágenes reales obtenidas de GitHub y de la herramienta de diseño. No se deben sustituir por imágenes recreadas que aparenten ser capturas de esas plataformas.
