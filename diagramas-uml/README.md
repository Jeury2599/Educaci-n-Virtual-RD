# Modelos UML

Esta carpeta contiene archivos fuente editables de cuatro modelos de Educación Virtual RD. Están escritos en PlantUML y pueden abrirse o exportarse con una herramienta compatible.

## Cómo revisarlos

1. Abre el archivo de texto que quieras revisar.
2. Copia su contenido en una herramienta compatible con PlantUML o ábrelo en un editor que permita previsualizar estos diagramas.
3. Comprueba los nombres y las relaciones con los requisitos del proyecto.
4. Exporta el modelo como imagen si necesitas insertarlo en el informe.

Los archivos son modelos de diseño, no capturas de Visual Paradigm Online. Si el profesor pide evidencias específicas de esa herramienta, debes abrir o reproducir los modelos allí y guardar capturas reales.
